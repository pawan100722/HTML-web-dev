1. Forms are used to take user inputs from UI
  2. The form in HTML is wrapped inside form tag.
  3. The most commonly used filed in form is
    1. The input tag has a type attribute which specifies type of the input
    2. Like , type="text". It creates check box which takes input as text
    3. By default the input type is text, even if the type attribute is not specified
  4. There is a label tag used to gives UI values for the input, . The for attribute must have the ID of the input field for which the label is

Attributes of input tag

  1. type: It specifies the type of the input field
  2. minLength: It sets the minimum length of the characters that can be typed in the input box
  3. maxLength: It specifies the maximum characters that a input box can have
  4. required: It makes the input files mandatory, the field can not be empty, otherwise there will be error shown in UI
  5. value: Specifies the default of the input, even if nothing is selected or changed
  6. disabled: Used to disable a input field
  7. name: Most useful for input type="radio", as the radios with same name, only one can be selected at one time
  8. placeholder: useful for input fields that inputs text or number or email, it is used to tell the user that what kind of value the input filed must have

Label Tag in HTML

  1. Label tag is span tag
  2. Label tag is used to give labels on text to the form fields text <label>. It is a paired tag
  3. It have a attribute for, the for attribute must have the ID of the input field, so when the label is clicked , the input whose ID will be in the for attribute of the label tag will get selected

Text Area in HTML

  1. Text area is used to make multiline text input box in HTML
  2. <textarea> </textarea>
  3. Text area is not a self closing tag, but a paired tag and expects a closing tag

Why Text area is a paired Element?

Because text area is used to create or store multi line text

Difference between value and placeholder

Placeholder is hint abut the input box, as soon as the user stats typing the hint disappears, but value is the actual input , whatever the user writes in the box
