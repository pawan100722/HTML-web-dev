Links in HTML

  1. Links are used to navigate, navigation can be on same page or different pages
  2. For navigation in HTML, anchor tag is used, <a>
  3. The anchor tag has a attribute "href", which is used to give URL to the link tag, where the link must be navigated
  4. Example of anchor tag Google

Attributes

  1. href: contains URL for navigation
    1. The href attribute can be used with different internet protocols.
    2. Like href="mailto:abc@email", used to send mai to the email id abc@email, with anchor tag
    3. Like href="tel:123456" can be used to call on the number 123456, with anchor tag
  2. target - used to decide where the link mut open, in same page or in next page

Default functionalities in anchor Tag

  • When a link is visited, its color gets changed
  • When link is hovered, the cursor gets pointer from
  • Bu default links are of blue color and underlined

Navigate within the page

To navigate within the page, the href attribute of the anchor tag must have the id of that section, followed by #. Like href="#idOFTheSection"

Reload the page

To reload the page - href="#"
